## 3. Erkannte Doppelungen und Prüfhinweise

1. **Quantum.AI:** Zwei Python-Webservices (`quantum-ai-zeah`, `quantum-ai-renewed`) plus ein statisches Frontend (`quantumai-chat`) verwenden dasselbe Repository. Das kann beabsichtigt sein, sollte aber als ein Produkt mit getrennten Komponenten dokumentiert werden.
2. **Quantum KI Ultra Pro V2:** Hauptservice und erneuerter Service laufen parallel; zusätzlich zeigt `Ionos-7` auf dasselbe Repository, aber mit abweichendem Startkommando.
3. **Legacy-KI-Deployments:** `UltraKI.AI` und `ultra-ki-v2` werden noch separat bereitgestellt, obwohl die READMEs die konsolidierte Hauptanwendung empfehlen.
4. **KI-Game-Mod:** Eigenständiger Render-Dienst läuft neben der integrierten Game-Mod-API in Quantum.MIrror.Wonderland; Quell-README kennzeichnet das Modul-Repository als historische Quelle.
5. **Aktiv-Lyca:** Zwei Node-Webservices zeigen auf dasselbe Repository.
6. **Rothshild:** Zwei Static Sites zeigen auf dasselbe Repository, veröffentlichen jedoch unterschiedliche Verzeichnisse.
7. **Lichtkrieger Cloud Gaming:** Der Render-Dienst ist statisch und veröffentlicht ein Verzeichnis aus Quantum.MIrror.Wonderland. Ein GPU-Streaming-Host oder WebRTC-Spielestream ist damit nicht nachgewiesen.
8. **Platzhalter:** Quantum.K, IONOS-8 und IPad-App.IONOS-7 haben laut README keinen vollständigen ausführbaren Anwendungscode; ihre aktiven Render-Dienste verdienen eine Funktions-/Kostenprüfung.
9. **Dokumentationsfehler:** `Ultra_KI_Merge/README.md` enthält sichtbare Git-Merge-Konfliktmarker. Das sollte vor einer Veröffentlichung bereinigt werden.
10. **E-Commerce:** Bei Drop-shipping weist das README Checkout und Lieferanten-API als noch nicht aktiviert aus. Bei BullRun/Rea.Signature/Parfum/Lyca sollten Live-Zahlungen, Lagerbestand, Versand und Webhooks separat getestet werden.

## 5. Grenzen dieser Bestandsaufnahme

Die Beschreibung stützt sich auf verfügbare Repository-README-Dateien und die Render-Service-Konfiguration (Name, Typ, Quell-Repository, Build-/Startkommando und Publish-Verzeichnis). Sie ist **keine vollständige Code-Sicherheitsprüfung, kein End-to-End-Funktionstest und keine Bestätigung aktiver Zahlungen, KI-API-Aufrufe, Trading-Ausführung oder GPU-Streaming**. Fehlende README-Dateien wurden nicht durch erfundene technische Details ersetzt.
